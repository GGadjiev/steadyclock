# SteadyClock — концепция дизайна «Quiet Focus»

Спокойный, премиальный интерфейс для трекера времени: тёплый фарфоровый фон, глубокий хвойно-зелёный акцент, мягкий шалфей и почти монохромная типографика. Идея — «тихая сосредоточенность»: интерфейс не кричит, а помогает удерживать ритм. Вдохновение — лучшие практики современных productivity-приложений, без копирования Trackabi.

## Визуальное направление

- **Настроение:** спокойствие, собранность, аккуратность, немного «редакционного» минимализма.
- **Фон:** тёплый фарфор `#F5F2EA`, а не холодный серый.
- **Акцент:** глубокий хвойный `#1E5B54`, поддерживающий текущий бренд SteadyClock.
- **Второй акцент:** мягкий шалфей `#A9C6BB` для статусов, тегов и спарклайна.
- **Микроакцент:** тёплый коралл `#E08A6A` — только для редких важных отметок.
- **Формы:** крупные скругления 20–24 px, тонкие рамки 1 px, почти без теней.
- **Графика:** едва заметные концентрические кольца за таймером — метафора устойчивого ритма.
- **Типографика:** Inter для интерфейса, JetBrains Mono для цифр таймера. Обе поддерживают кириллицу.
- **Принцип:** один главный акцент на экран, один главный CTA, много воздуха.

## Типографика

- **UI:** Inter, 400 / 500 / 600. Размеры: H1 28–32 px, H2 18–20 px, body 14–15 px, caption 12–13 px.
- **Таймер:** JetBrains Mono, 500 / 600, табличные цифры, 64–72 px в главном окне.
- **Межстрочный интервал:** 1.4–1.5 для текста, 1.0–1.1 для крупных цифр.
- **Особенность:** цифры таймера не «дёргаются» при обновлении — используйте tabular numerals.

## Радиусы, отступы, движение

- Карточки: 20–24 px. Поля ввода: 12–14 px. Кнопки и статусы: pill (999 px).
- Базовая сетка: 4 px; основные отступы: 16 / 20 / 24 / 32 px.
- Анимации: 150–200 ms ease-out. Пульсация точки статуса — только в состоянии «Работает», очень деликатная.
- Без резких вспышек, неоновых свечений и тяжёлого glassmorphism.

## Экраны

### 1. Главный экран, светлая тема
`final/01-main-light.jpg`

- Крупный таймер `01:24:36` — визуальный центр.
- Статус «Работает» с мягкой точкой.
- Одна главная кнопка «Пауза»; «Стоп» — вторичное действие.
- Карточка «Сегодня»: итог `4 ч 12 мин`, `3 сессии`, семидневный спарклайн.
- Список сессий как таймлайн: интервал, тег, длительность, редактирование и удаление.
- Внизу — «Добавить запись вручную», платформы и подсказка горячей клавиши.

### 2. История
`final/02-history.jpg`

- Сводка: сегодня / за неделю / всего.
- Дни сгруппированы в карточки, у текущего дня — тонкий хвойный акцент слева.
- Внутри — таймлайн сессий с длительностью и действиями.
- Прокрутка остаётся лёгкой: видна часть следующего дня.

### 3. Настройки
`final/03-settings.jpg`

- Вместо длинной простыни — боковое меню категорий: «Таймер», «Режим трекера», «Простой», «Трей», «Клавиши», «Уведомления», «Напоминания».
- Справа — выбранный раздел «Простой»: порог бездействия, автопауза, логика вычитания простоя.
- Слайдер, переключатели и radio-карточки в одном визуальном языке.
- Внизу — фиксированные «Отмена» и «Сохранить».

### 4. Модальное окно новой записи
`final/04-new-entry.jpg`

- Центрированная карточка поверх затемнённого главного окна.
- Дата, начало, конец, длительность, комментарий.
- Спокойная иерархия: форма не конкурирует с таймером.
- Кнопки «Отмена» / «Сохранить» справа.

### 5. Главный экран, тёмная тема
`final/05-main-dark.jpg`

- Глубокий графитово-зелёный фон, тёплый светлый текст.
- Мятный статус и аккуратные акценты.
- Та же структура и те же данные, что в светлой теме.
- Ощущение «тихой комнаты», а не неоновой панели.

### 6. Дизайн-система
`final/06-design-system.jpg`

- Логотип и знак.
- Палитра с HEX-кодами.
- Шрифтовая пара Inter + JetBrains Mono.
- Компоненты: кнопка, статус, переключатель, поле ввода, карточка таймлайна.

## Что улучшено по сравнению с текущим интерфейсом

1. **Появился характер:** тёплый фарфор и хвойный зелёный вместо нейтрального серого.
2. **Усилена иерархия:** таймер, статус и одно главное действие считываются мгновенно.
3. **День стал понятнее:** итог, количество сессий и семидневный ритм собраны в одну карточку.
4. **История стала таймлайном:** легче сканировать интервалы и паузы.
5. **Настройки перестали быть длинной простынёй:** боковая навигация и один раздел за раз.
6. **Модальные окна приведены к общей системе:** поля, отступы, кнопки, фокус.
7. **Добавлена тёмная тема:** без потери читаемости и без неона.
8. **Собран дизайн-кит:** палитра, шрифты и компоненты перенесены в Avalonia.
